# ESP32 온습도 알림

집의 온습도를 ESP32로 측정하고, 가습기를 켤 시점을 헤르메스 봇으로 알려주는 프로젝트.

> 현재는 기획 초안 단계입니다. 펌웨어·서버·헤르메스 연동은 아직 구현하지 않았습니다.
> 보유 중인 ESP32 보드와 센서의 정확한 모델은 확인이 필요합니다.

## 목표

- 집 안 온도와 상대습도를 주기적으로 측정한다.
- 습도가 낮은 상태가 지속되면 기존 헤르메스 봇을 통해 알림을 받는다.
- 습도가 회복되거나 센서 연결에 문제가 생기면 상태를 알린다.
- 같은 상태의 알림이 반복되지 않도록 한다.

첫 버전은 측정과 알림까지 구현한다. 가습기 전원 자동 제어는 추후 검토한다.

## 전체 구성

```mermaid
flowchart LR
    Sensor[온습도 센서] --> ESP32[ESP32]
    ESP32 -->|집 Wi-Fi / 측정값 전송| Server[온습도 수집 서버]
    Server -->|알림 조건 판단| Hermes[헤르메스 봇]
    Hermes --> Telegram[텔레그램 알림]
```

ESP32는 측정과 전송을 담당하고, 서버는 최신 측정값과 알림 상태를 관리한다.
헤르메스와의 실제 연동 방식은 운영 환경에서 지원하는 전송 경로를 확인한 후 결정한다.

## 필요한 장비

| 항목 | 현재 상태 |
| --- | --- |
| ESP32 개발 보드 | 보유 여부 및 모델 확인 예정 |
| 온습도 센서 | 보유 여부 및 모델 확인 예정 |
| USB 전원·케이블 및 연결 부품 | 보드·센서 확인 후 점검 |
| 집 Wi-Fi | 사용할 보드와 연결 가능 여부 확인 예정 |
| 상시 실행 서버 및 헤르메스 봇 | 수집 서버 배치 위치·연동 경로 확인 예정 |

배선과 센서 라이브러리는 실제 모델을 확인한 후 정한다.

## 알림 동작 예시

아래 수치는 논의를 위한 예시이며, 확정된 설정이나 운영 중인 정책이 아니다.

| 항목 | 예시 |
| --- | --- |
| 측정·전송 주기 | 1분 |
| 건조 판단 | 상대습도 40% 미만이 10분 지속 |
| 회복 판단 | 건조 알림 후 상대습도 45% 이상으로 회복 |
| 통신 이상 | 5분 동안 유효한 측정값이 수신되지 않음 |
| 중복 방지 | 건조·회복·통신 이상 상태가 바뀔 때 한 번 알림 |

알림 문구 예시:

```text
💧 거실 습도가 낮아요.
현재 22.4°C / 37%RH
10분 동안 건조 상태가 이어졌어요. 가습기를 확인해주세요.
```

## 구현 순서

1. 보유한 보드·센서 모델 확인 및 배선 결정.
2. ESP32에서 온습도 측정, 시리얼 출력 확인.
3. Wi-Fi 연결과 서버 전송 구현.
4. 수집 서버와 알림 상태 판단 구현.
5. 헤르메스 전송 경로 확인 및 연결.
6. 집에서 측정값·알림 수신·재연결 동작 검증.

구체적인 요구사항과 검증 항목은 [구현 계획](docs/PLAN.md)에 정리한다.

## 저장소 관리

- 프로젝트 경로: `~/codex/esp32/temp`.
- Wi-Fi 비밀번호, 장치 인증값, 봇 토큰 등 실제 비밀값은 커밋하지 않는다.
- 모델별 핀 번호와 운영 주소는 확인 후 문서화한다.
- 측정값 예시와 실제 장치·서버·텔레그램에서 검증한 결과를 구분해 기록한다.
