# ESP32 프로젝트

ESP32를 활용한 집 안 센서·알림 프로젝트를 기능별 폴더로 관리한다.

| 프로젝트 | 설명 | 상태 |
| --- | --- | --- |
| [temp](temp/README.md) | 온습도 측정 및 헤르메스 봇을 통한 가습기 사용 알림 | 기획 초안 |

현재 작성된 문서는 [온습도 프로젝트 소개](temp/README.md)와
[구현 계획](temp/docs/PLAN.md)이다. 펌웨어·수집 서버·알림 연동은 아직 구현하지 않았다.

Wi-Fi 비밀번호, 장치 인증값, SSH 개인키, 봇 토큰 등 비밀값은 저장소에 커밋하지 않는다.
